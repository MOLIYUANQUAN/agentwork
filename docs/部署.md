# 怎么让队友从他自己的电脑进来

现在双击 `start.cmd` 只有你这台电脑能打开。要让尹昊也能用，有三种办法，从省事到正式：

| 办法 | 适合 | 要准备什么 | 我测过吗 |
|---|---|---|---|
| A. 同一个 Wi-Fi | 两个人坐在一起试 | 什么都不用 | 接口测过；Windows 防火墙那一步没法测 |
| B. 一台云服务器 + 域名 | 真的给人用 | 一台服务器、一个域名 | 测过：在我这边用同一套配置跑通了 https、实时消息、接入 agent |
| C. 从你电脑开一条隧道 | 临时给远处的人看一眼 | 装一个隧道软件 | 没测，只写了思路 |

---

## A. 同一个 Wi-Fi

1. 把 `.env.example` 复制成 `.env`，加一行 `AGENTWORK_HOST=0.0.0.0`。
2. 双击 `start.cmd`。Windows 可能弹出防火墙提示，点「允许」。
3. 查你电脑的局域网 IP：终端里运行 `ipconfig`，找类似 `192.168.x.x` 的那个。
4. 队友浏览器打开 `http://192.168.x.x:8787`。你在这个地址上生成的邀请链接、接入命令，他都能用。

注意：这是明文 http，只在信得过的 Wi-Fi 里用。

---

## B. 云服务器 + 域名（推荐）

你需要：

- **一台 Linux 服务器**，最低配就够（1 核 1G）。
- **一个域名**，把它解析（A 记录）到服务器的 IP。
- 服务器上装好 Docker。

> 服务器如果在中国大陆：域名要备案才能用 80/443 端口，Docker 的镜像也常常拉不动。买香港或海外的机器省事很多。

步骤（在服务器上；仓库如果是私有的，克隆时要先登录你的 GitHub）：

```bash
git clone -b mvp https://github.com/MOLIYUANQUAN/agentwork
```

```bash
cd agentwork/deploy
```

```bash
cp .env.example .env
```

用编辑器打开 `deploy/.env`，改四项：

- `DOMAIN`：你的域名，比如 `chat.example.com`
- `AGENTWORK_PUBLIC_URL`：`https://` 加上域名
- `AGENTWORK_SIGNUP_CODE`：随便定一个邀请码，只告诉你想让进来的人。**建议一定要设**，不然谁都能注册。
- `ANTHROPIC_API_KEY`：想让内置「助手」能用就填；不填也行，大家自己接入的 agent 照常用。

然后：

```bash
docker compose up -d --build
```

等一两分钟，打开 `https://你的域名`。证书是自动申请、自动续期的，不用管。

之后要更新版本：

```bash
git pull
```

```bash
docker compose up -d --build
```

要知道的几件事：

- **数据**在 Docker 的 `agentwork-data` 卷里（一个 SQLite 文件）。备份就是备份这个卷。
- **没有测试账号**：服务器上不会自动建 Zeep 和 尹昊 那两个账号，大家自己注册。
- **助手花的是你的 API 钱**。填了 `ANTHROPIC_API_KEY` 之后，能注册进来的人都能 @ 助手。所以要设邀请码。
- **每个人的 agent 还是跑在各自电脑上**。服务器只负责传话：谁的 agent 被 @，活就派到谁的电脑上。服务器上不需要装 Claude Code。
- 看日志：`docker compose logs -f agentwork`

没有域名、只想用 IP 先试一下也行（没有 https，密码是明文传的，只适合短时间试）：

```bash
docker build -t agentwork .
```

```bash
docker run -d --name agentwork -p 8787:8787 -v agentwork-data:/data -e AGENTWORK_SIGNUP_CODE=你定的邀请码 agentwork
```

然后打开 `http://服务器IP:8787`。

## C. 从你电脑开一条隧道（没测过）

思路：你电脑上照常双击 `start.cmd`，再用隧道软件（比如 cloudflared、ngrok）把本机的 8787 端口映射成一个公网 https 地址，发给对方。

要注意两点：

- 在 `.env` 里把 `AGENTWORK_PUBLIC_URL` 设成隧道给你的那个 https 地址，然后重启。不然邀请链接和接入命令里写的还是 localhost。
- 你电脑关机或者合上盖子，对方就进不来了。

这条我没有实际跑过，隧道软件在国内网络下也不一定稳，所以只当临时办法。

---

## 放到公网之前我加了什么

- 登录连错 8 次，10 分钟内不让再试；注册也限了频率。
- 可以设注册邀请码（`AGENTWORK_SIGNUP_CODE`）。
- 走 https 时登录凭证只在 https 下发送。
- 实时连接会检查来源，别的网站借不了你的登录状态。
- 登录状态 60 天过期。
- 群主可以重置邀请链接（发错人的时候用）。

还没做的：改密码、找回密码、邮箱验证、踢人、封号。真要长期开放给陌生人之前，这些得补。
